# voke 已知限制（KNOWN-ISSUES）

> 当前 Go + mygo 实现已确认的限制与预期行为；未来工作见 [`BACKLOG.md`](BACKLOG.md)。
> Rust/gpui 时代的问题已随参考实现归档，见 [`legacy/`](legacy/README.md)。

## 1. 默认热键只对新配置生效

- **现象**：全新安装（无配置文件或未写 `hotkey`）使用默认 `Alt+Space`；旧配置里已落盘的
  热键不会被自动改写。
- **原因**：配置加载原样读取用户值，只有非法/缺失时才回落默认。
- **处理**：不迁移，属预期行为。老用户可在设置页改键，或删除 `config.toml` 的 `hotkey` 行。

## 2. 面板总在主显示器唤起

- **现象**：多显示器环境下，面板固定在主显示器 WorkArea 居中，不跟随鼠标所在屏。
- **原因**：显式对齐旧版行为（`PrimaryDisplay()`），且跟随指针屏需要先处理各屏
  DPI/WorkArea 夹紧；当前未做。
- **处理**：产品决策项，见 BACKLOG。

## 3. 托盘 awake 文案在菜单打开期间不刷新

- **现象**：菜单已弹出时，倒计时/状态不会实时变化；关闭再打开或面板显隐后才是最新值。
- **原因**：mygo 的 `Tray.SetMenu` 在调用时取菜单快照，没有 `WM_INITMENUPOPUP` 之类
  的弹出前钩子。当前在 awake 状态变化、面板 show/hide 时重建菜单。
- **处理**：受 mygo 能力限制；若上游提供弹出前回调可再优化。

## 4. 键盘输入后不抑制 hover 高亮

- **现象**：鼠标停在某行时，即使随后改用键盘导航，鼠标所在行仍保留 hover 高亮。
- **原因**：旧版会记录“最后一次输入来自键盘还是指针”并在键盘输入时抑制 hover；
  mygo 只有 `Hovered()` 查询、没有 `OnHover` 回调，自维护该状态不确定性和收益不匹配。
- **处理**：暂不做，见 BACKLOG。

## 5. 中文 query 排序偏后

- **现象**：「微信」这类汉字查询通常比拼音 `weixin` 得分低，命中性不受影响，排序偏后。
- **原因**：汉字只匹配原名，nucleo 的子串分数量级低于拼音 fuzzy；详见
  [`notes/matching.md`](notes/matching.md)。
- **处理**：是否对汉字路径单独加成待定。

## 6. 系统应用英文名搜不到

- **现象**：MSIX 显示名是中文（如「终端」）时，只建了拼音/首字母键，`terminal`
  搜不到「终端」。
- **原因**：搜索键来自显示名；没有维护英文名 → 显示名别名表。
- **处理**：与上游同类工具行为一致，待产品决策。

## 7. 应用列表只覆盖 `shell:AppsFolder`

- **现象**：开始菜单 Applications 文件夹中的应用（含桌面程序快捷方式与 packaged 应用）
  才能被搜索；散落在桌面或自定义目录、且不在开始菜单的 `.lnk` 不会出现。
- **原因**：迁移后复用 mygo `Shell.InstalledApps`，不再像旧版那样解析任意 `.lnk` 并合并来源。
- **处理**：属既定架构取舍；若需要可另做 `.lnk` 来源，见 BACKLOG。

## 8. `Win+Shift+S` 截图时面板偶发消失（低优先级）

- **现象**：面板在前台时按截图键，偶发被失焦逻辑隐藏。
- **原因**：截图覆盖层下的前台/激活语义不稳定；Go 版沿用失焦即隐藏。
- **处理**：低优先级，真机复现后再考虑加失焦延迟判定。

## 9. Go exe 没有 VERSIONINFO

- **现象**：设置页「关于」显示注入的版本号，但 exe 文件属性里没有版本资源。
- **原因**：Go 构建链当前只通过 `-ldflags -X` 注入字符串，未生成 Windows 资源段。
- **处理**：已知差距；安装器 AppVersion 与产物文件名不受影响，见 BACKLOG。

## 10. 向管理员窗口粘贴每次都需要 UAC

- **现象**：目标窗口以管理员权限运行时，粘贴会弹一次 UAC；取消后内容只留在剪贴板，
  面板重新显示并提示手动粘贴。终端 profile 的 `Ctrl+Enter` 提权打开同样需要 UAC。
- **原因**：UIPI 会静默拦截低完整性进程的 `SendInput`，必须由提权进程代发粘贴键。
  voke 不常驻高权限进程，辅助进程完成一次粘贴即退出；提权标签页还要求 Windows
  Terminal 自身开启“允许提权”。
- **处理**：预期行为。受保护进程或 SYSTEM 窗口即使提权也可能无法操作，此时统一回退为
  “已复制，请手动粘贴”。

## 11. 插件全局快捷键可能被系统或其它程序占用

- **现象**：录制某个组合时设置页提示“占用”并回滚；或启动日志里出现插件热键注册失败，
  该插件快捷键不生效。
- **原因**：`RegisterHotKey` 是系统级独占注册，`Alt+\`` 等常见组合可能已被其它工具
  占用；运行期间无法注册不代表配置非法。
- **处理**：换一个组合即可，不影响主热键与其它插件；插件快捷键注册失败只影响该插件，
  其余功能正常。

## 预期行为（不是 bug）

- **托盘鼠标**：左键单击不动作，左键双击唤起面板，右键打开菜单。
- **插件快捷键不做 toggle**：面板隐藏时唤起并直达该插件，已在该插件时只聚焦（保留
  过滤词），在其它位置时切换过去；隐藏统一走主热键 / `Esc`。
- **录制热键时全部暂停**：设置页录制期间主热键与所有插件热键挂起，录制结束或取消后
  按当前配置恢复。
- **覆盖安装**：安装器会在复制文件前强制结束正在托盘的旧实例（无未保存数据），
  不弹“请手动退出”。
- **设置窗关闭即销毁**：再次打开会重新建窗，首帧稍慢但不会常驻 GPU 资源。
- **图标缓存裁剪**：面板隐藏 10 秒后解码缓存降到 64 条；设置窗打开时跳过。
- **日志上限**：默认 9999 行，跨启动追加，超限从头部删一批。
