## 发布前人工冒烟

- **真机端到端清单**：热键即时生效；托盘右键菜单与 awake 状态（面板 show/hide 后
  刷新）；左键双击唤起；自启注销/重登；前缀冲突提示与旧配置迁移；权重组内顺序；
  深色/浅色/跟随系统；单实例二次启动唤起；安装器覆盖安装（旧实例自动结束）与卸载。
- **剪贴板插件真机清单**：复制文本 / HTML（浏览器）/ RTF（Word / WordPad）/ 图片
  后能在 `@c` 看到；粘贴回原窗口（GUI Ctrl+V、conhost / Windows Terminal /
  mintty 等 Shift+Insert）；管理员窗口触发 UIPI 回退提示；复制文件不采集；
  密码管理器标记的内容不采集；Voke 自身 Copy / 普通粘贴不产生重复条目；
  `Ctrl+Enter` 富文本转纯文本；置顶 10 条上限与条数上限设置即时生效。
- **窗口结束任务真机清单**：普通应用（可弹保存提示）、无响应应用（约 6 秒后强杀）、
  多窗口同进程（所有窗口一起关闭）、管理员权限窗口（拒绝并提示）、explorer 与
  核心系统进程的边界、全局结果与 `#` 进入窗口插件的两种入口。
- *为什么*：这些是窗口/托盘/安装器等真机行为，headless 测试覆盖不到。

## 待修 / 产品决策

- **枚举失败后的立即重试与退避**：首载失败目前依赖「下次唤起距 ≥60s 再扫」恢复；
  缺「改查询时立即重试一次」与指数退避。*为什么*：避免 Shell 未就绪时每次按键重试
  抖动，同时让失败恢复更快。`[低-中成本]`
- **跟随指针屏唤起**：当前总在主显示器。需要先把面板尺寸/坐标按目标屏 WorkArea 与
  缩放夹紧，再决定是否作为产品能力。*为什么*：旧版也没有该能力，且副屏 DPI 是独立
  问题。`[中成本，需先修 DPI 夹紧]`
- **键盘输入后抑制 hover 高亮**：mygo 无 `OnHover` 回调，需要自维护「最后输入来源」
  状态。*解除条件*：上游提供 hover 回调，或真机测量轮询成本后确认值得。`[被 mygo 限制]`
- **apps 无前缀时的模式令牌 / 只逛 `#` 不打字是否枚举**：两处手感/文案决策。
  *为什么*：无前缀插件进入后令牌为空；picker 里只浏览不输入时不触发应用枚举（懒加载）。
  `[产品决策]`
- **`view.go` 纯文案派生函数的归属**：`placeholder` / `hintLine` / `pluginPending` /
  `pendingHint` / `pickerHint` 目前留在 `internal/app`，可选下沉到独立 logic 子包。
  *为什么*：纯归属整理，行为不变，不挡功能。`[低优先级]`
- **中文 query 排序加成**：汉字查询得分低于同义拼音，影响直接输入中文的排序手感。
  *为什么*：nucleo 子串分数量级天生低于 fuzzy；是否单独加成待定。`[产品决策]`
- **MSIX 英文名别名表**：显示名为中文的应用（如「终端」）搜不到英文名。
  *为什么*：需要维护英文名 → 显示名映射；与上游同类工具行为一致。`[产品决策]`
- **`Win+Shift+S` 截图时面板偶发消失**：低优先级，真机复现后再决定是否加失焦延迟。
- **桌面/自定义目录 `.lnk` 来源**：当前只枚举 `shell:AppsFolder`；不在开始菜单的快捷方式
  搜不到。*为什么*：迁移时选择复用 mygo 枚举、避免维护第二套 `.lnk` 解析与去重。
  `[中成本，按需]`
- **VERSIONINFO 注入**：Go exe 文件属性没有版本资源；需要生成 Windows 资源段或加 syso 版本。
  *为什么*：设置页与安装器版本正常，只影响文件属性/资源管理器显示。`[低成本，可选]`
- **上游 mygo 维护风险（bus factor = 1）**：接受「上游停更则自行 fork」，还是保留 Rust
  退路。*为什么*：产品决策，不是当前技术缺口。`[待拍板]`

## 内存优化

当前状态与实测见 [`notes/memory.md`](notes/memory.md)。

- **已落地**：设置窗关闭销毁；解码/PNG 图标缓存有界；隐藏 10s 裁到 64 条；
  面板关闭 resize/vibrancy/transparent；日志行数上限。
- **剩余**：~110MB 的主要部分是 mygo/D3D11/DirectWrite 与系统枚举的原生地板；
  隐藏窗口在 Windows 上无法靠 mygo 停帧。*为什么*：继续压低的收益与风险需要单独评估，
  不做 `EmptyWorkingSet` 这类只改读数的 trick。`[暂不处理]`
